# Cómo vender el primer día

## 1. Crea tu empresa

Regístrate con correo y contraseña, escribe el nombre del negocio y entra al espacio de trabajo. El catálogo comienza vacío para que cada empresa tenga sus propios datos.

## 2. Agrega productos

Abre **Catálogo**, crea al menos tres productos con nombre, código, precio, costo y stock mínimo. Si recibiste mercancía, registra la entrada desde **Compras** para que el stock quede auditado.

## 3. Invita al equipo

Desde **Miembros**, invita al vendedor y al cajero con sus roles. El vendedor prepara preventas; el cajero cobra. Cada usuario solo opera dentro del tenant al que pertenece.

## 4. Prepara una preventa

El vendedor abre **Preventa**, busca productos, ajusta cantidades y revisa el total. Puede agregar una referencia liviana de evidencia. Pulsa **Enviar a caja** y comparte el código grande del ticket.

## 5. Cobra

El cajero abre **Caja**, escribe o pega el código, revisa los ítems y elige efectivo, tarjeta o crédito. Al confirmar, el sistema crea la venta, descuenta stock una sola vez y muestra un ticket listo para imprimir.

## 6. Revisa el negocio

El dueño puede volver al **Resumen** para consultar ventas del día, stock bajo, tickets pendientes y cartera. Usa **Reportes** para rangos de fechas y exportación CSV.

> Regla práctica: el stock sale al cobrar, no al preparar la preventa.
