# Tienda-SS

**Sistema Logístico e Inventario Profesional**

Aplicación web para gestión de inventario, ventas, rutas de entrega y administración de una tienda.

## Roles disponibles

| Rol       | Función                                      |
|-----------|----------------------------------------------|
| **Bodega**   | Registrar productos, controlar stock y cámara |
| **Vendedor** | Caja, catálogo y facturación                 |
| **Chofer**   | Gestión de rutas y entregas                  |
| **Jefe**     | Panel de administración y métricas           |

## Accesos de prueba

- Usuario: `bodega`, `vendedor`, `chofer` o `jefe`
- Clave: `1234` (o usar los botones de acceso rápido)

## Tecnologías

- **Next.js 15.5.24**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- Preparado para **Firebase** (Firestore)
